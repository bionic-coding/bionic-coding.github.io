Column groups on the page: "Base tokens" (Input, Output) and "Prompt caching" (Cached Input, 5m writes, 1h writes). Column tooltips:

- Cached Input: "Cached input is billed at this rate; each hit automatically refreshes the cache entry's TTL (time-to-live)."
- 5m writes: "Writing a prompt prefix into the context cache with a 5-minute TTL (time-to-live); this is the default tier when no TTL is specified."
- 1h writes: "Writing a prompt prefix into the context cache with a 1-hour TTL."

Note: The Kimi API **automatically enables** context caching billing for repeated request prefixes, with a default TTL (time-to-live) of 5m. For TTL settings and cost optimization tips, see [Best Practices for Context Caching](https://platform.kimi.ai/docs/guide/context-caching).

## Concepts

> Model inference on the Kimi API platform is billed on a pay-as-you-go basis, with no subscription plan. It differs from products such as the Kimi membership and Kimi Code. [See the product comparison](https://platform.kimi.ai/docs/guide/product-plans).

### Billing Unit

Token: A token represents a common sequence of characters. The number of tokens used for each English character may vary. For example, a single character like "antidisestablishmentarianism" might be broken down into several tokens, while a short and common phrase like "word" might use just one token. Generally speaking, for a typical English text, 1 token is roughly equivalent to 3-4 English characters. The exact number of tokens generated by each call can be obtained through the [Token Calculation API](https://platform.kimi.ai/docs/api/estimate).

### Billing Logic

Model inference APIs bill both Input and Output based on usage. For K3 series models, cache writes are billed separately by TTL (5min / 1h); cached input is billed at the cache-hit price only, with no additional cache write charge. If you upload and extract content from a document and then pass the extracted content as Input to the model, the document content will also be billed based on usage. File-related APIs (file content extraction and file storage) are **temporarily free**: if you only upload and extract a document, the file APIs themselves incur no charges. For tips on improving cache hit rates and choosing a TTL tier, see [Best Practices for Context Caching](https://platform.kimi.ai/docs/guide/context-caching).
