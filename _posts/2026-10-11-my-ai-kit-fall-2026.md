Everything in this post is swappable — the models, the harnesses, even the editor. The one piece that stays is [Crux](https://github.com/bionic-coding/crux), my own layer that ties it all together. I'll get to it near the end, but keep it in mind as you read: the rest of this list is interchangeable parts.

I used to start with a Primary and Alternate model, but I really don't think that way anymore.
This has allowed me to reduce the cost of intelligence to the point where some days the average is as low as 25 cents per million tokens. See the table in the models section for my current list.

## The TLDR (Too Long; Didn't Read)

Don't try to replicate all of this at once. [Zed](https://zed.dev) + [Claude Code](https://www.anthropic.com/claude-code) gets you most of the way there with one subscription and one install. Sign up for API access to the other models so that you can use them in the council. And grab [Crux](https://github.com/bionic-coding/crux) to ensure that your agents plan and execute.

## "Editor"

I am calling this a text editor loosely. Traditionally these were used to edit code.

Now it's a combination of an agentic harness and a text editor.

A LOT of people used [Cursor](https://cursor.com) historically. You should pick something else these days.

I use [Zed Editor](https://zed.dev) using [ACP](https://zed.dev/acp) (the Agent Client Protocol) to call [Claude Code](https://www.anthropic.com/claude-code), [OpenCode](https://opencode.ai), or [Codex](https://openai.com/codex).

## Crux

[Crux](https://github.com/bionic-coding/crux) is the layer I promised at the top — the reason the rest is swappable. The models and harnesses above are swappable; Crux is the part that stays. It's a set of skills and agents that runs in every harness. A few pieces do most of the work:

- **A real project memory.** Crux keeps the intent — architecture decisions, research, briefs, a work journal — as plain Markdown any model can read. The docs are the source of truth; the code stays disposable. It's the [manifesto]({{ "/manifesto/" | relative_url }}) turned into a working system.
- **The council.** The "LLM-as-judge" I keep mentioning: Crux puts a decision to several models at once — Claude, GPT, and Gemini — and has them deliberate, agree, or dissent. That way I'm not stuck with one model's blind spot.
- **Sourced research.** Instead of prompting a model cold, a Crux agent writes the research prompt, captures the source, and files it with a citation. Nothing goes in unsourced.
- **Repeatable cycles.** For real work, Crux runs a plan → build → review loop with the council gating the plan — the same process every time, not vibes.
- **Human decisions have momentum, agentic decisions do not.** Crux has been recently updated to distinguish between human and agentic decisions to ensure that choices made by a model don't carry the same weight as human decisions.

## What I'm no longer using

When Fable first launched I was trying to drive with it, but it's too expensive.
Not only is it more expensive than Opus but it also uses more tokens. This combination
raised my token costs more than 4x.

I do use Astra. It seems to be a level of intelligence above Sol, Opus and even Fable.

## What I'm doing to cut costs

Since GPT-6.1 Sol Pro launched, I have been experimenting with it in multiple roles. This caused some pain last week but I am still using it as much as possible for key roles.
